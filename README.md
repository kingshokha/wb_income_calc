# WB Income Pro — Калькулятор юнит-экономики Wildberries

Современный веб-калькулятор юнит-экономики для продавцов Wildberries (FBW / FBS) с визуальной аналитикой и гибкой настройкой параметров.

## 🚀 Возможности

- **Модели продаж (FBW / FBS):** Переключение логистики и расчет комиссий с автоматической подгрузкой для различных категорий.
- **Расчет скидки СПП:** Учет Скидки Постоянного Покупателя в процентах и показ итоговой цены для покупателя.
- **Полная юнит-экономика:**
  - Розничная цена (выручка)
  - Скидка СПП %
  - Себестоимость товара (закупка + упаковка)
  - Логистика WB (%)
  - Хранение на складах WB (%)
  - Расходы на рекламу и продвижение (%)
  - Прочие издержки (брак, фулфилмент)
  - Налог (%)
- **KPI Показатели:** Мгновенный расчет Чистой прибыли, Маржинальности (%) и Окупаемости инвестиций (ROI %).
- **Категории товаров:** Возможность создавать, редактировать и удалять собственные категории с индивидуальными процентами комиссий.
- **Умная аналитика (Бизнес-инсайт):** Автоматические рекомендации по оптимизации экономики товара в зависимости от показателей маржи.
- **Автосохранение:** Все параметры сохраняются в браузерном локальном хранилище (`localStorage`) для каждой категории.
- **Экспорт отчета:** Быстрое копирование структурированного отчета в буфер обмена в один клик.

## 🛠 Технологии

- HTML5 / Vanilla JavaScript
- [Tailwind CSS CDN](https://tailwindcss.com/)
- [Alpine.js](https://alpinejs.dev/)
- FontAwesome Icons & Google Fonts (Inter)

## 📦 Запуск

Калькулятор не требует установки серверов или сборщиков. Достаточно открыть файл `index.html` в любом современном браузере.
